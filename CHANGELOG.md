## [1.0.0] - 2026-10-27

### Added

- Initial release of the `product-design` skill.
- `SKILL.md`: mode selection, five-lens cheat sheet, P0–P7 workflow, quality gates, output discipline.
- `references/01-five-lenses.md`: core models, concept glossaries, diagnostic questions, limits, and misuse for all five books.
- `references/02-workflow.md`: detailed P0–P7 playbook with interview scripts, artifacts, and a full consumer case.
- `references/03-heuristics.md`: lens-selection decision tree, 25 if-then rules, 20 anti-patterns, ethics, review scoring, metric library.
- `references/04-b-end-and-ai.md`: B2B experience framework, scenario maps, workspace/feedback/activation/messaging patterns, AI "six swords", measurement selection.
- `assets/design-brief.md`: one-page design brief template.
- `assets/review-checklist.md`: seven-dimension review checklist with scoring and verdict rules.
- `scripts/validate.mjs`: zero-dependency validation of structure, frontmatter, resource references, local links, and code fences.
- `scripts/install.ps1` and `scripts/install.sh`: installers for DSH, Claude Code, or project-local skill roots.
- GitHub Actions workflow to run validation on push and pull request.
- Bilingual README (`README.md`, `README.en.md`), contribution guide, MIT license.
